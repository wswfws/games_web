# Block Blast

Клон головоломки Block Blast на React + TypeScript (Vite): два режима —
соло-рекорд и партия против бота на общем поле. Классика: поле 8×8,
лоток на 3 фигуры, очистка полных строк/столбцов, комбо и стрик,
рекорд в localStorage. Фулскрин-лейаут под десктоп и мобильные.

## Запуск

```bash
npm install
npm run dev      # дев-сервер
npm run build    # проверка типов + прод-сборка
npm run preview  # предпросмотр сборки
```

Требуется Node.js 20+.

## Режимы

- **Меню** (экран по умолчанию): выбор режима, показан рекорд.
- **На рекорд** — классика: один игрок, лоток на 3 фигуры, игра
  заканчивается, когда фигуры некуда ставить. Рекорд — в localStorage.
- **Против бота** — общее поле на двоих, ходы по очереди (человек первый).
  Фигуры противника видны. Лоток восполняется сразу после хода, у каждого
  свой счёт. Партия до **100 фигур на двоих**; больше очков — победа.
  Если хода нет — автопас, два паса подряд завершают партию.

## Правила

- Перетащи фигуру из нижнего дока на поле (или выбери фигуру и кликни клетку).
- Полные строки и столбцы сгорают.
- Очки: +1 за каждую клетку фигуры, +10 за каждую сгоревшую клетку, бонус за несколько линий сразу и за серию очисток подряд.
- Когда в лотке закончились фигуры — выдаётся новый набор.
- В соло игра заканчивается, когда ни одну оставшуюся фигуру некуда поставить.

## ИИ

Два разных алгоритма — соло и versus.

**Соло-бот** — как в примере для «4 в ряд» (`GetNextMoveBot`):
рекурсивный перебор своих ходов на глубину + эвристика позиции + рандом
при равных оценках. Соперника в дереве нет, поэтому перебираются
последовательности установок фигур, а не минимакс.

- `suggestAiMove(board, tray, depth, tuning, streak)` — лучший первый ход
  (свой ход + лучшие ответы из остатка лотка).
- `evaluateBoard` — вес почти собранных линий (7/6/5 заполненных — это
  заделы под будущие очистки), минус занятость поля, дыры и рваный периметр.

**Versus-бот** — минимакс на общем поле (`suggestVersusMove`). Отличия:
- лотки обоих видны, поэтому ход бота оценивается вместе с лучшим
  ответом соперника: значение узла = очки бота − очки соперника
  (`oppGainPenalty`), соперник играет оптимально против бота;
- почти собранные линии — это «утечка», её может добить соперник:
  веса 7/6/5 в versus идут со знаком минус (`leakWeight7/6/5`), а не
  как задел в плюс, как в соло;
- глубина — `tuning.versusDepth` (2): на общем поле ходы чередуются,
  длинный перебор своих ходов подряд бессмыслен.

- Тупиковые ветки (ходить нечем) штрафуются `deadEndPenalty`.
- Все числа — в `src/features/ai-move/config/tuning.ts` (`AI_TUNING`).
- Код: `src/features/ai-move/` (`config/tuning.ts`, `lib/ai.ts`).

Режим «против бота»: `features/versus-game/useVersusSession` — общее поле,
очередность, счёт и восполнение фигур; бот ходит через `suggestAiMove`.

## Бенчмарк ИИ

Прогоняет N полных игр без UI (та же механика, что в `useGameSession`:
лоток, сжигание, стрик, конец игры) и печатает среднее/медиану/мин/макс:

```bash
npx tsx scripts/bench.ts --games 100 --depth 2 --seed 42
```

Флаги: `--games` (по умолчанию 100), `--depth` (глубина перебора,
по умолчанию из тюнинга), `--seed`
(сид RNG: один seed = воспроизводимый прогон, удобно сравнивать тюнинг).

Коэффициенты бота можно переопределять прямо из командной строки,
не трогая код:

```bash
npx tsx scripts/bench.ts --games 100 --seed 42 --set "holePenalty=20,setupWeight7=60"
```

Ключи — любые поля из `AI_TUNING` (`defaultDepth`, `clearCellPoints`,
`comboPerExtraLine`, `megaComboMinLines`, `megaComboBonus`,
`setupWeight7/6/5`, `filledCellPenalty`, `holePenalty`, `deadEndPenalty`).
Неизвестный ключ или не-число — ошибка с подсказкой. В PowerShell
значение `--set` бери в кавычки, иначе запятая разобьёт аргумент.

> Важно: `npm run bench -- --games 100` не пробросит флаги (npm их
> съедает) — запускай через `npx tsx` как выше.

## Автоподбор коэффициентов

Координатный спуск по весам из `AI_TUNING` (по очереди ×0.5 / ×2,
оставляем улучшение; все кандидаты играют одни и те же партии,
в конце — валидация на свежих сидах):

```bash
npx tsx scripts/tune.ts --games 12 --depth 2 --seed 100 --passes 3
```

Флаги: `--games` (партий на замер), `--depth`, `--seed`,
`--passes` (макс. проходов), `--params "holePenalty,setupWeight7"`
(подмножество весов; по умолчанию все непрерывные, кроме
`defaultDepth` и `megaComboMinLines`).

Результат tune-2026-09-05 (алгоритм v2: стрик в поиске + штраф периметра):
`clearCellPoints` 40 → 20, `comboPerExtraLine` 50 → 25,
`perimeterPenalty` 1 → 2. Валидация на глубине 4 (6 игр, seed 999):
50727 → 69000 (+36%). До этого v1: `clearCellPoints` 10 → 40 (×3.6).

## Стек

- React 19, TypeScript (strict), Vite
- Без стейт-менеджеров и UI-библиотек — только React-хуки и CSS
- Архитектура — Feature-Sliced Design, импорт через алиас `@` → `src/`
- Модуль Module Federation (`remoteEntry.js`): вход `App` принимает каталог как хост

## Структура `src/`

```
app/                      композиция: App (микро-роутер меню/соло/versus),
                          глобальные стили
pages/
  game-page/              соло-режим: раскладка виджетов
  versus-page/            партия против бота на общем поле
widgets/                  main-menu, score-header, versus-header, board,
                          piece-tray, bot-tray, float-messages,
                          game-over-modal
features/
  game-session/           хук useGameSession — соло-механика:
                          установка, стрик/комбо, drag&drop,
                          выбор фигуры, рестарт, конец игры
  versus-game/            хук useVersusSession — общее поле, очередь,
                          раздельные счёт/стрик, авто-восполнение лотка,
                          до 100 фигур, победитель по очкам
  ai-move/                solo: suggestAiMove + evaluateBoard;
                          versus: suggestVersusMove (минимакс против
                          соперника на общем поле)
entities/
  board/                  типы, чистые функции поля
                          (canPlace/applyPlace/clearFullLines),
                          презентационный BoardGrid
  piece/                  ShapeDef/TrayPiece/DragState, каталог
                          из 30+ фигур, рандом, PieceView/DragPreview
  score/                  подсчёт очков, рекорд (localStorage)
shared/                   константы (размеры, палитра), PageKind,
                          геометрия указателя, Button
```

Зависимости идут строго сверху вниз: `app → pages → widgets → features → entities → shared`. Игровая логика — чистые функции в `entities`, состояние и оркестрация — в `features/*-game`, компоненты — презентационные.
